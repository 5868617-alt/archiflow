# ArchiFlow

**האתר:** https://archiflow-topaz.vercel.app · **הדגמה עם נתונים לדוגמה:** https://archiflow-topaz.vercel.app/demo

מערכת לניהול משרדי אדריכלות ועיצוב פנים: פרויקטים, לקוחות, שרטוטים, מפרטים, רכש, תקציב ביצוע, שכר טרחה, אישורי לקוח ופורטל לקוח.
הממשק כולו בעברית ומימין לשמאל.

האתר הוא אפליקציית React סטטית שמחוברת ישירות ל-Supabase (מסד נתונים, התחברות, אחסון קבצים).
כל ההרשאות נאכפות במסד הנתונים עצמו (RLS ופונקציות שרת), לא בממשק.

## מה עובד באמת ומה עדיין לא

| עובד בייצור | עדיין לא מחובר |
|---|---|
| הרשמה, אימות מייל, התחברות, איפוס סיסמה | **שליחת מיילים:** המיילים נכנסים לתור, ונשלחים רק אחרי שמגדירים מפתח Resend ודומיין מאומת |
| יצירת משרד, הזמנת צוות ולקוחות | **סליקה וחשבוניות:** אין ספק תשלום. אין חיובים, ושינוי מסלול נרשם כבקשה |
| כל המודולים: קריאה וכתיבה למסד עם RLS | **המרת DWG/DXF:** אין תצוגה מקדימה. PDF ותמונות מוצגים |
| העלאת קבצים לאחסון פרטי ופתיחה בקישור חתום | **סנכרון יומן:** לא קיים |
| שינויי סטטוס ואישורי לקוח דרך פונקציות שרת, עם היסטוריה | **בדיקה אוטומטית של שרטוטים:** לא קיימת. ממצאים מוזנים ידנית ואינם אישור הנדסי |
| משימות מתוזמנות: תפוגת ניסיון, הזמנות שפגו, תזכורות | |

מחירים, חלוקת יכולות בין המסלולים והנחות הרשאה הם **הנחות דמו** שמחכות לאישור. הן מסומנות כך בממשק ומפורטות ב-[docs/open-decisions.md](docs/open-decisions.md).

## מבנה הריפו

| נתיב | תוכן |
|---|---|
| `site/` | האתר הבנוי, כולל manifest, service worker ואייקונים. זה מה ש-Vercel מגיש |
| `public/` | קובצי האפליקציה להתקנה (אייקונים, manifest, service worker) שמועתקים ל-`site/` בבנייה |
| `src/` | קוד המקור: React + TypeScript |
| `src/live/` | החיבור ל-Supabase: לקוח, טעינת נתונים, מנוע הסנכרון, מסכי התחברות |
| `supabase/migrations/` | 11 מיגרציות: סכמה, אבטחה, פונקציות, אחסון, תזמונים |
| `supabase/tests/` | בדיקות האבטחה של המסד (168 בדיקות) |
| `supabase/functions/send-emails/` | Edge Function ששולחת את תור המיילים דרך Resend |
| `tests/e2e/` | בדיקות דפדפן מקצה לקצה: סריקת מסכים ו-53 זרימות כתיבה |
| `tools/` | בדיקות של גרסת ההדגמה (ללא מסד) |
| `docs/` | אפיון, ארכיטקטורה, אבטחה, עיצוב, תפעול והחלטות פתוחות |
| `CLAUDE.md` | כללי העבודה על הפרויקט |

## בנייה

```bash
npm run build:site   # בונה את האתר המחובר ומעדכן את site/index.html
npm run build:demo   # גרסת הדגמה עם נתונים בדויים, ללא מסד
```

ה-build משתמש ב-esbuild. React 18.3.1 נטען מ-cdnjs בייצור.
את `site/index.html` צריך לבנות מחדש ולעשות לו commit אחרי כל שינוי ב-`src/`, כי Vercel לא מריץ build.

## בדיקות

```bash
npm run test:db                                           # בדיקות האבטחה על PostgreSQL מקומי
npm run test:e2e:setup && npm run test:e2e:gateway &      # מסד בדיקה + שרת שמדמה את Supabase
npm run test:e2e:crawl && npm run test:e2e:flows          # סריקת מסכים וזרימות כתיבה
```

פירוט מלא ב-[docs/testing.md](docs/testing.md).
