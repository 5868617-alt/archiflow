# מערכת עיצוב

**הקונספט:** שולחן שרטוט. סרגל צד בכחול כהה בצד ימין, כמו "חותמת שרטוט", ומשטח עבודה בגוון נייר חם.
רשת שרטוט עדינה משמשת במשורה. הצהוב שמור לפעולה הראשית בלבד.

כל הערכים מוגדרים ב-`src/styles/01-tokens.css`. קומפוננטות משתמשות רק במשתנים, לא בערכים קשיחים.

## צבעים (מצב בהיר)

| תפקיד | משתנה | ערך |
|---|---|---|
| רקע | `--bg` | `#F5F3EE` |
| נייר / משטח | `--paper` / `--surface` | `#FBFAF7` / `#FFFFFF` |
| קווים | `--line` / `--line-strong` | `#E3DFD5` / `#CEC8BA` |
| טקסט | `--ink` / `--ink-2` / `--ink-3` | `#15213B` / `#47526B` / `#7A8296` |
| סרגל צד | `--navy` | `#15213B` |
| פעולה ראשית | `--accent` | `#F2B705` (טקסט עליו `--accent-ink`) |
| קו שרטוט | `--blueprint` | `#6F8FC0` |
| הצלחה / אזהרה / שגיאה / מידע | `--ok` / `--warn` / `--bad` / `--info` | `#2E7656` / `#A66A0B` / `#B13A3A` / `#2D5C99` |

לכל צבע מצב יש גרסה רכה (`--ok-soft` וכו') לרקע של תגיות והודעות.

**מצב כהה:** מוגדר ב-`prefers-color-scheme: dark`, ואפשר לכפות מצב עם `data-theme`.

## טיפוגרפיה
- **כותרות:** Frank Ruhl Libre (`--font-display`).
- **גוף:** IBM Plex Sans Hebrew (`--font-body`).
- **מספרים ומידות:** IBM Plex Mono (`--font-mono`).
- **סולם:** 12 / 13 / 14 / 16 / 20 / 26 / 34px (`--fs-xs` עד `--fs-3xl`). גוף הטקסט 14px.

## צורה
- **רדיוסים:** 4 / 6 / 10px.
- **צללים:** שלוש רמות (`--shadow-1..3`).
- **סרגל צד:** 248px. **סרגל עליון:** 60px.

## רכיבים
ב-`src/ui/core.tsx`:
- כפתורים: ראשי צהוב, משני, שקט ומסוכן.
- כרטיסים, טבלאות, תגיות סטטוס.
- Callout, Modal, Drawer, Tabs.
- טפסים עם תוויות מעל השדה.
- מצבים ריקים עם פעולה.

## סימונים מיוחדים
- **`AssumeTag`:** "הנחת דמו" או "טעון אישור", ליד כל הנחה עסקית שלא אושרה.
- **`DemoTag`:** "הדגמה". מופיע רק בגרסת ההדגמה. בגרסה המחוברת הוא לא מוצג.
- **ממצאי שרטוט:** תמיד עם הכיתוב "לא אישור הנדסי".

## RTL ונגישות
- הפריסה כולה RTL. אייקוני כיוון (חצים) מתהפכים.
- **ניגודיות:** טקסט רגיל לפחות 4.5:1, וגם `--ink-3` עומד בזה על `--surface`.
- כל פעולה זמינה מהמקלדת, עם focus גלוי.
- כל מסך נבדק ב-1366px וב-400px, בלי גלילה אופקית.
