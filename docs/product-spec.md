# אפיון המוצר

ArchiFlow היא מערכת SaaS לסטודיו לאדריכלות ועיצוב פנים. כל משרד הוא דייר נפרד, עם צוות, לקוחות ומנוי משלו.

## משתמשים ותפקידים

| תפקיד | מי זה | מה רואה |
|---|---|---|
| בעלים (owner) | מי שפתח את המשרד | הכול במשרד, כולל מנוי וחיוב |
| מנהל משרד (admin) | ניהול שוטף | כל הפרויקטים והכספים. ניהול חיוב הוא הנחת דמו |
| חבר צוות (member) | אדריכל או מעצב | רק פרויקטים שהוא משויך אליהם. כספים רק אם הבעלים אפשרו |
| לקוח (client) | איש קשר של לקוח המשרד | פורטל לקוח: רק פריטים שסומנו "משותף" בפרויקטים שלו |
| Super Admin | צוות הפלטפורמה | משרדים, מנויים, פניות ויומן ביקורת. **לא** תוכן פרויקטים |

## סטטוסי פרויקט (קבועים)

ליד חדש ← תכנון ראשוני ← תכנון בפיתוח ← ממתין לאישור ← תכנון מאושר ← ביצוע ← לקראת מסירה ← הושלם. בנוסף: בהשהיה.

הסטטוס משתנה רק בפעולה גלויה, דרך פונקציית השרת `set_project_status`. כל שינוי נרשם בהיסטוריית הפרויקט וביומן הביקורת.

## מודולים

### סביבת המשרד
- **היום שלי:** משימות שלי, אישורים ממתינים, פגישות היום, התראות תקציב.
- **פרויקטים:** רשימה, לוח לפי סטטוס, דף פרויקט עם לשוניות (סקירה, משימות, שרטוטים, מפרטים, מסמכים, תקציב, שכר טרחה, פגישות, אישורים, פעילות).
- **לקוחות ואנשי קשר:** הזמנה לפורטל לקוח.
- **משימות:** רשימה וקנבן, תבניות עבודה לפי סוג פרויקט, משימות מתוך הערות על שרטוט.
- **יומן ופגישות:** זימון וסיכום פגישה ללקוח. המייל נכנס לתור.
- **שרטוטים ותכניות:**
  - ספרייה, גרסאות והעלאת PDF או תמונה.
  - צופה עם נעצים, ממצאים ומדידה ידנית אחרי כיול קנה מידה.
  - השוואת גרסאות.
  - DWG/DXF נשמרים, אבל אין להם תצוגה.
- **מפרטים:** פריטים, חלופות ושליחה לאישור לקוח.
- **מסמכים:** העלאה, גרסאות, שיתוף עם הלקוח.
- **אישורי לקוח:** בקשה, תזכורת, ביטול. ההחלטה של הלקוח נשמרת עם חותמת זמן.
- **ספקים והזמנות רכש** (מסלול Pro).
- **כספים:**
  - **תקציב ביצוע:** מה הלקוח משלם לספקים ולקבלנים.
  - **הוצאות** עם קבלות.
  - **שכר טרחה:** אבני דרך ודרישות תשלום.
  - שני התחומים מוצגים בנפרד, ויש גם תצוגה משולבת.
- **הודעות לקוחות, התראות.**
- **הגדרות משרד, צוות והרשאות, מנוי וחיוב, עזרה ותמיכה.**

### פורטל לקוח
בית, אישורים ממתינים, שרטוטים (רק הגרסה האחרונה, בלי הערות פנימיות), מסמכים, פגישות, שיחה עם המשרד והיסטוריית החלטות.
סיכום תקציב ללקוח מוצג רק אם המשרד אפשר זאת. זו הנחת דמו.

### Super Admin
סקירה, מדדי שימוש, משרדים, משתמשים, מנויים, מסלולים ותמחור, יומן שינויי מחיר, פניות תמיכה, הודעות מערכת, אירועי מערכת, יומן ביקורת, מדיניות שמירת מידע והגדרות פלטפורמה.

### ציבורי
התחברות, הרשמה, אימות מייל, שכחתי סיסמה, קבלת הזמנה ואשף פתיחת משרד.
