# החלטות פתוחות

כל מה שכאן מסומן בממשק "הנחת דמו" או "טעון אישור". רוב ההחלטות נשמרות כנתונים או כהגדרות במסד, כך שאפשר לשנות אותן בלי לשנות קוד.

## עסקי ותמחור
- [ ] **מחירים:** ₪149 / ₪299 לחודש, ו-₪124 / ₪249 בתשלום שנתי. האם כולל מע״מ?
- [ ] 14 ימי ניסיון.
- [ ] **חלוקת היכולות בין Starter ל-Pro:** פורטל לקוח, רכש ושכר טרחה רק ב-Pro?
- [ ] **מגבלות:** 3 / 10 משתמשים, 10 פרויקטים פעילים ב-Starter. האם הזמנות ממתינות נספרות במכסה?

## חיוב
- [ ] **ספק סליקה וחשבוניות**, כולל תאימות לחשבונית מס בישראל. אחרי הבחירה:
  - webhook שמעדכן את `office_subscriptions` ו-`invoices` עם service role,
  - אחרי אימות חתימה.
- [ ] חיוב יחסי בשדרוג, ושנמוך שנכנס לתוקף בסוף התקופה.
- [ ] מה קורה כשהשימוש חורג מהמגבלות אחרי שנמוך.
- [ ] 7 ימי חסד אחרי חיוב שנכשל.
- [ ] 90 יום של קריאה בלבד אחרי ביטול, ואז מחיקה.

## הרשאות
- [ ] האם חבר צוות רואה כספים. כרגע: רק אם הבעלים הפעילו.
- [ ] האם חבר צוות רואה את כל הפרויקטים. כרגע: רק משויכים.
- [ ] האם מנהל משרד מנהל חיוב.
- [ ] האם לקוח רואה סיכום תקציב.
- [ ] התחזות של Super Admin למשרד לצורכי תמיכה. כרגע: לא קיימת.
- [ ] חובת MFA לבעלים ול-Super Admin.

## תהליכים
- [ ] **שכר טרחה:** מעקב גבייה בלבד, או גם הפקת דרישות תשלום וחשבוניות.
- [ ] **ספקים וקבלנים:** בלי חשבון ב-MVP. הזמנת הרכש נשלחת במייל. האם להוסיף PDF?
- [ ] **הפקת PDF** להזמנות רכש, לסיכומי פגישות ולדרישות תשלום.

## טכני
- [ ] **מיילים:** מפתח Resend ודומיין שולח מאומת. אחרי זה גם SMTP מותאם למיילי האימות של Supabase.
- [ ] **המרת DWG/DXF ותמונות ממוזערות:** איזה שירות חיצוני.
- [ ] **סנכרון יומן** (Google / Outlook).
- [ ] **בדיקה אוטומטית של שרטוטים:** אם תיבנה, היא תוצג כ"הערות עזר" ולעולם לא כאישור הנדסי.
- [ ] **מעבר ל-Next.js:** לא בוצע, כי בסביבת הבנייה לא הייתה גישה ל-npm. הקוד הוא React רגיל, והמעבר אפשרי בהמשך.
- [ ] **בדיקת טיפוסים מלאה:** חסרות חבילות `@types/react`.

## משפטי
- [ ] **הצהרת נגישות:** להשלים שם, טלפון ומייל של רכז/ת הנגישות, ולשקול בדיקה של מורשה/ית נגישות.
- [ ] **מדיניות שמירת מידע:** הטיוטה במסך ה-Super Admin טעונה בדיקה משפטית.
- [ ] תנאי שימוש ומדיניות פרטיות.
- [ ] ייצוא נתונים ומחיקת משרד לבקשת הלקוח.
